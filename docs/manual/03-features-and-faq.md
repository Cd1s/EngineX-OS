# EngineX OS 全功能使用手册与常见问题 FAQ

适用版本：EngineX OS 5.3.0.2 及以后（带 `#99`、`#100` 的开发中功能会单独标注）。
适用机型：SC5000 / SC5000M / SC6000 / SC6000M / PRIME 4 / PRIME 2 / PRIME GO / Mixstream Pro 等一代机，二代机（`/data` 数据包）功能略有差异，见各节说明。

> **关于 Beta**：标「测试版」的功能没有在所有真机上验证过，上台前先在家里试一遍。

## 1. 流媒体

### 1.1 先说清楚：现在是 7 个平台，不是 8 个

碟机音源菜单里内置：**网易云音乐、Spotify、Deezer、SoundCloud、TIDAL、Beatport、Apple Music**，共 7 个。

- **QQ 音乐目前没有登录入口**，也没有下载实现，所以不能在碟机上登录。代码里只有一处 `QQ Music` 的显示名（先锋 CDJ 看流媒体文件来源时用），不代表功能可用。
- **TIDAL** 走 Engine 原厂自己的登录流程，不是 EngineX 的手机扫码页。
- 所有平台共用同一套体验：碟机和手机连同一个 Wi-Fi，在音源菜单点开平台，**用手机相机扫屏幕上的二维码**，在手机页面完成登录。手机页默认英文，右上角可切简体中文或繁體中文，每个页面都有分步教程。
- 二维码是会过期的一次性链接，**只登录对应服务，不会打开碟机的网页控制台**，俱乐部里扫了你屏幕的人拿不到碟机控制权。

### 1.2 各平台登录方法

| 平台 | 怎么登录 | 注意 |
| --- | --- | --- |
| 网易云音乐 | 用**网易云音乐 App 里的「扫一扫」**扫碟机屏幕二维码并确认 | 不要用手机相机或微信扫。二维码过期后点屏幕上「点这里换一个新二维码」。只有一部手机时，先用相机拍下二维码，再在 App 扫一扫里选相册里的照片。网易云是**唯一**提供「官方直连 / Deemix 优先」双通道切换的平台（见 1.4） |
| Spotify | **方式 A（推荐，局域网 Spotify Connect 一键配对）**：手机或电脑打开 Spotify App，播放任意歌曲，点右下角「连接设备」（音箱图标），在列表中点 **`EngineX OS`**，约 1 秒自动完成账号绑定。**方式 B（碟机屏幕二维码）**：在碟机音源列表点 Spotify 右侧的「扫码登录（Scan to log in）」，用手机相机扫码，在手机页面完成 OAuth 授权或填入凭证 | 不再需要申请开发者 Client ID（旧的 `#70` 做法已取消）。详见 1.2a |
| Deezer | 在碟机音源列表点 Deezer 右侧的「扫码登录」，手机扫码后在页面粘贴你自己的 **Deezer `ARL` Cookie**（页面里有教程，演示怎样在电脑上从 deezer.com 复制） | 系统自动识别账号歌单，并把 `ARL` 同步到本机下载引擎，立即解锁 FLAC 无损。公开固件不内置任何人的私人凭据。只填资料页链接则只显示公开歌单，不能下载。详见 1.2b |
| SoundCloud | 填用户名或主页链接即可 | 不用密码，也不用申请 API。私密歌单在「高级」里粘贴 soundcloud.com 的 `oauth_token`。Go+ 专享曲目和非 Set 单曲的取源规则见 1.4「SoundCloud Go+ 智能路由」 |
| Beatport | 填 Beatport 邮箱和密码 | 碟机只保存登录令牌，不保存密码。用你自己的订阅：Professional 下载 FLAC 或 256k AAC，Advanced 下载 128k AAC，Essential 只能在线播放 128k AAC。**未用真实账号完整验证**，遇到问题请反馈 |
| Apple Music | 见 1.3 | 不需要账号也能用公开歌单 |
| TIDAL | 在 Engine 原厂的 TIDAL 页面登录 | 选中其他流媒体服务时，不会再弹出 Engine 5.3.0 的「Connect to your Engine DJ Profile to use Tidal」提示 |

### 1.2a Spotify 原生直连与两种登录

> **状态：** 随下一次发版上线（写作时尚未随当前 Release 发布），菜单文字以发布版为准。

- **方式 A：局域网 Spotify Connect 一键配对（推荐）。** 手机或电脑和碟机在同一局域网；打开 Spotify App，播放任意歌曲，点右下角「连接设备」（音箱图标），在列表中点 **`EngineX OS`**，约 1 秒自动完成账号绑定。**无需申请开发者 Client ID，也无需扫码。**
- **方式 B：碟机屏幕二维码扫码登录。** 在碟机音源列表点 Spotify 右侧的「扫码登录（Scan to log in）」，用手机相机扫码，在手机页面完成 OAuth 授权或填入凭证。
- **独立原生音源。** Spotify 曲目直接从 Spotify 拉取 **320kbps Ogg Vorbis** 原生音频上盘播放，**不走 Deemix，也不用网易云兜底**。
- **局域网零配置发现。** `stream-sync` 内置纯 Go 的 `_spotify-connect._tcp.local.` mDNS 广播器（配合 Avahi 服务），有线 `eth0` + 无线 `wlan0` 双网卡环境下，同一局域网的手机 Spotify App 也能秒级发现 `EngineX OS`。
- **双通道只属于网易云。** 只有**网易云音乐（NetEase）**提供「官方直连 / Deemix 优先」双通道切换；Spotify、Beatport、Apple Music 都严格走各自独立的音源，不做跨平台兜底。SoundCloud 与 Deezer 的取源规则见 1.4。

### 1.2b Deezer 每用户独立 ARL 扫码登录（解锁 FLAC 无损）

公开固件不内置任何人的私人凭据。要使用 Deezer 无损流媒体：

1. 在碟机音源列表点 Deezer 右侧的「扫码登录」；
2. 手机扫码后，在页面粘贴你自己的 **Deezer `ARL` Cookie**；
3. 系统自动识别你账号里的歌单，并把 `ARL` 同步到本机下载引擎，**立即解锁 FLAC 无损**加载。

不要把自己的 `ARL` 发到 Issue、日志或截图里。

### 1.3 Apple Music 的实际做法（没有 Face ID 扫码）

仓库里没有任何 Face ID 相关实现，请不要按「Face ID 扫码授权」来理解。真实流程是：

1. **只看公开歌单或专辑**：在手机页粘贴 `music.apple.com` 的歌单或专辑链接，不需要账号。
2. **想浏览自己的资料库**：在手机页点「用 Apple Music 登录」（MusicKit JS，`#75`）。Apple 不允许在手机页登录时，页面会给出一个**书签脚本**：在 music.apple.com 登录后运行它，它会复制你的 `media-user-token`，再粘贴回手机页。
3. **音频从哪来**：EngineX 解锁了 Engine 5.3.0 自带的 `AppleMusicProvider`（原厂登录与播放），音频由 Apple Music 自己提供；EngineX 不再按 ISRC 或歌名去 Deezer、网易云找替身，也不做跨平台兜底。手机页的歌单链接和 `media-user-token` 只用于浏览资料库。

### 1.4 音质与缓存

- `设置 → 服务 → 流媒体音质`（`Settings → Services → Streaming Quality`）：**Lossless（无损 FLAC）** 或 **320kbps MP3**。
- SoundCloud 按最高可用音质取：上传者原档（允许下载时，如 320k MP3 / WAV / FLAC）→ 256kbps AAC → 160kbps AAC → 128kbps MP3；没有原档时两档结果相同。
- 只有网易云有 `设置 → 服务 → 网易云下载方式`（Spotify、Deezer、SoundCloud、Beatport 没有这个开关）：`Official（官方直下）` 或 `Deemix 优先`（先走 Deemix，省网易云自己的每月下载额度，失败再回退官方）。
- 播放过的曲目缓存在碟机内部存储（`/data/enginex/Stream`），再次加载直接秒开，不会重复下载。

**各平台缓存规则（独立缓存与 Deemix 智能共享）**

- **各平台独立下载、独立缓存。** Spotify（`spotify-<id>.*`）、Beatport（`beatport-<id>.*`）、SoundCloud（`soundcloud-<id>.*`）以及「官方直连（Official）」模式的网易云音乐（`netease-<id>.*`）各自使用独立的下载通道和专属缓存命名空间。即使同一首歌曾在 Deezer 或网易云下载过，在 Spotify 点播也会走 Spotify 自己的流程重新拉取并独立缓存，互不混用。
- **网易云（Deemix 模式）与 Deezer 共享缓存。** 网易云开启「Deemix 优先」时，底层同走 Deemix 无损音源：在网易云点播过的歌切到 Deezer 点播同一首（或反之），会直接复用已下载的无损缓存文件，不重复下载。网易云切回「官方直连（Official）」后，与 Deezer 各自独立缓存。

**SoundCloud Go+ 智能路由**

- **DJ Set / 长混音（超过 10 分钟）**：始终直连 SoundCloud 官方流，优先取上传者原始 320k / WAV 母带，其次 256k / 160k AAC 或渐进式 MP3。
- **Go+ 专享曲目与非 Set 普通单曲**：
  1. 已绑定有 **SoundCloud Go+** 订阅的账号：优先直连 SoundCloud 官方高音质流；
  2. 没有 Go+：Go+ 专享曲目（官方只给 30 秒试听）和非 Set 普通单曲，会自动在本机**已登录的其他流媒体（Deezer / 网易云 / Beatport）**里匹配并拉取无损 / 320k 音频，缓存为 `soundcloud-<id>.*` 上盘播放；
  3. 其他流媒体都没登录（或曲目是 SoundCloud 独占作品）：直连 SoundCloud 播放；遇到必须 Go+ 的试听曲目又没有任何可用平台，碟机会明确提示扫码登录 SoundCloud Go+ 或其他流媒体账号。
- 歌单里每首歌加载前就能看到 BPM 和调性。

### 1.5 为什么长时间待机不会掉线

不是靠「永不过期」，而是各平台有各自的**自动续期**：

- Beatport：访问令牌在到期前 300 秒自动用刷新令牌更换；接口拒绝时也会自动续一次。
- Spotify：令牌过期后用刷新令牌自动更换。
- SoundCloud：令牌自动续期。
- Apple Music：开发者令牌在到期前一天自动刷新。
- 凭据都留在碟机本地，不经过云端；登录令牌文件权限为仅本人可读。

自动续期失败（比如你在别处改了密码、刷新令牌被撤销）时，碟机会提示登录失效，**重新扫一次码**即可，不用删任何文件。网易云、Deezer 的登录有效期由对方平台决定，EngineX 没有额外承诺。

### 1.6 OmniSource：一次搜索同时查 U 盘和全部流媒体

- 打开：`配置 → 曲库 → OmniSource（在流媒体中显示 U 盘/SD）`（`Profile → Library → OmniSource (Drives in Streaming)`）选 **On**（默认关闭）。
- 效果：流媒体浏览器里，U 盘 / SD 卡里**带 Engine 曲库**的歌单和曲目，和已登录服务的歌单并排显示；搜索时同时搜本地盘和各平台。
- U 盘曲目直接从盘上读取播放，**音质不打折**，不用换音源菜单。
- 只读：EngineX 只读取这些数据库，不会改写。
- 目前 U 盘里的 WAV / AIFF 文件不在这个列表里（只列 FLAC、MP3、M4A、AAC），WAV / AIFF 请走正常的 U 盘音源。

## 2. Rekordbox 与先锋 CDJ

### 2.1 Rekordbox U 盘零等待直插（`rb-bridge`）

给先锋 CDJ 导出的 Rekordbox U 盘，直接插到碟机上：

- **不需要**在电脑上用 Engine DJ 重新转换。
- 首次插盘 **2 秒内**读取，同一张盘再次插入约 **0.03 秒**（按 `export.pdb` 的大小和修改时间判断没变就直接跳过）。
- 自动转换的内容：歌单（含嵌套文件夹）、**Hot Cue（保留颜色）**、Memory Cue、Loop、拍线（BeatGrid）、封面，以及 rekordbox 里的三频段 / RGB 波形数据。
- 文件系统：Windows 的 `FAT32` / `exFAT` / `NTFS`，Mac 的 `HFS+`（`Mac OS 扩展`）都能插上直读。不支持 `APFS`：Mac 上请把 U 盘格式化为 `exFAT` 或 `Mac OS 扩展`。
- 异常拔盘造成的数据库损坏会自动修复，也去掉了「未安全弹出」的报错弹窗。
- rekordbox 6.8.5 导出的 U 盘即使有个别文件损坏也能导入，那几首在加载时再分析。

**需要知道的边界（别误会成「完全等同」）：**

- Engine 原生只有 **8 个 Hot Cue 槽（A–H）**。这些槽只放 Rekordbox 的 Hot Cue，**不会**拿 Memory Cue 去填。第一个 Memory Cue 对应 Engine 的主 Cue 点；全部 Memory Cue 另外保存，但原厂界面不能全部显示。
- 8 色 Hot Cue 的颜色按 Rekordbox 的颜色导入；没有 RGB 颜色的老 Cue 使用先锋的默认色。
- 被移除的曲目不会自动从 Engine 里删掉；歌单成员会同步。
- 加密的 OneLibrary 无法解密，会明确报错。
- 没有 Rekordbox 导出、只有 Engine 原生曲库的盘，直接旁路，什么都不改。

### 2.2 波形配色：Denon / RGB / 3-Band

- 位置：`配置 → 显示 → 波形样式`（`Profile → Display → Waveform Style`），或下拉**控制中心**里的波形样式磁贴，点一下立即切换，不弹确认。
- `3-Band` 是先锋风格三频段波形；`RGB` 是高对比度彩色波形；`Denon` 是原厂绿。

### 2.3 天龙读先锋 CDJ-3000 上的 U 盘

- 前提：碟机和 CDJ 在同一局域网（网线直连或交换机互联，Wi-Fi 也行但更慢）。
- 打开：`设置 → 服务 → Pro DJ Link 曲库`（`Settings → Services → Pro DJ Link Library`）选 **On**（默认关闭）。
- 之后在音源里出现 `Pro DJ Link 曲库`，可以浏览 CDJ 上 rekordbox U 盘的曲库并加载。
- **测试版**：开发者没有先锋实体机，主要用自研的 [OpenProLink](https://github.com/Cd1s/OpenProLink) 虚拟 CDJ-3000 联调。接真机表现请大家实测反馈。

### 2.4 先锋 CDJ-3000 读天龙 U 盘，以及天龙下载的流媒体（`#63` + `#100`）

- 打开：`设置 → 服务 → Pro DJ Link 导出至 CDJ（测试版）`（`Settings → Services → Pro DJ Link Export to CDJ (Beta)`）选 **On**（默认关闭，实验功能）。
- 开启前先插好含 `PIONEER/rekordbox/export.pdb` 的 U 盘；多个盘时选 `/media` 下按名称排序的第一个。换盘后需要先关再开，才会重新读取曲库。
- 碟机会向 CDJ 暴露只读的 NFS 和 dbserver，CDJ 就能浏览并加载这张盘。碟机自己占用一个空闲的播放器编号（按 4→3→2→1 选未占用的；四个都被占就不公告）。
- **`#100`（工作区开发中，本手册写作时尚未合入主干）**：开启后，碟机已下载的**流媒体曲目**会出现在 CDJ 的一个叫 **`EngineX Streaming`** 的文件夹里，CDJ 可以直接浏览并播放，文件显示的平台名（Deezer / SoundCloud / NetEase / Apple Music / Spotify / Beatport / TIDAL）来自下载记录。碟机上没有 U 盘曲库时，流媒体下载也会单独导出给 CDJ。时长对 mp3 / m4a 是估算值，CDJ 上显示的长度可能略有误差。
- 只读：CDJ 不能写入、不能越出 U 盘目录。

### 2.5 Master 与 Beat Sync

- 碟机和 CDJ 之间**始终只有一个 Master**，MASTER 可以双向交接。
- 碟机当 Master 时会发出 BPM 和拍点，供 CDJ 的 BEAT SYNC 对拍。

## 3. 4 轨视图、影子轨道与 View 1~5

### 3.1 开启 4 轨（SC5000 / SC6000 系列的独立播放机）

1. `布局 → ENGINEX 视图预设 → 联机视图（Layout → ENGINEX VIEW PRESET → Linked View）` 选 **`4 轨（4 Decks）`**。修改后 Engine 会自动重启一次。
2. `布局 → ENGINEX 视图预设 → 四轨角色（Layout → ENGINEX VIEW PRESET → 4-Deck Role）` 选择这台负责哪两轨：

| 选项 | 含义 |
| --- | --- |
| `自动` | Engine 播放器编号为奇数就是 `1+3`，偶数就是 `2+4` |
| `1+3` | 负责第 1、3 轨（常用作 Player 1） |
| `2+4` | 负责第 2、4 轨（常用作 Player 2） |
| `1+2` | 负责第 1、2 轨 |
| `1` / `2` | 只负责单轨 |

- 声卡仍然只出 2 路声音（你自己负责的那两轨）。其余轨是**不出声的影子轨道**。
- 屏幕上滑动加载时，只会加载到你负责的轨道，其余被锁定（避免误加载到别人的轨）。
- 二代机（SC LIVE、PRIME 4+、PRIME 4 G2 等）当前没有 4 轨解锁，64 位 AZ04 Engine（PRIME 4 G2 / SYSTEM ONE）已对齐（#149：16 处补丁、DSP 防护、软限幅、自动增益、SQLite 调优）。

### 3.2 影子波形怎么跟随对端

影子轨道跟随另一台 EngineX 碟机，或一台 CDJ-3000（按 Pro DJ Link 的播放器编号）：

- **曲目**：对端加载什么歌，本机拿到同一首的副本，显示真实歌名（没有标签的文件也一样）；对端从流媒体浏览器加载的歌也能跟随。
- **播放 / 暂停 / 按住 CUE 预听**：边沿在几十毫秒内同步，按住 CUE 时本机也显示预听。
- **Hot Cue / CUE 点**：对端的 Hot Cue 和 CUE 点会写到影子轨道，波形、总览和 Pad 上都能看到标线。**CDJ 不报告 Hot Cue**，所以跟 CDJ 时没有这些标线。
- **速度**：跟随对端的变速推子；位置漂移过大才会补一次跳转。
- **Master 与 Beat Sync**：影子轨道可以请求 Master、跟随对端的 Sync。跟 CDJ 时，CDJ 开着 BEAT SYNC，影子轨道会在 Engine 里同步。
- 实测延迟在几十到一百多毫秒量级，取决于网络。**这是视觉跟随，不是音频同步**：影子轨道不出声。

注意：影子轨道需要复制对端的音频文件到本机才能画波形，所以两台机器要在同一局域网。

### 3.3 View 1~5 与「保存视图」（`#99`，工作区开发中）

> 本节根据工作区里尚未提交的代码编写。合入主干并发布前，请以实际界面为准。

- 位置：顶部下拉切换至 **`布局（Layout）`** 页。原厂只有 3 个视图，EngineX 扩成 **View 1 ~ View 5**。
- 每个视图保存一整套布局：碟机样式、碟机数量、波形数量、波形方向、Pad 区是否显示、FX 区是否显示、曲库视图、封面。
- 在布局管理器里改的设置，会自动记到**当前选中的视图**；也可以点 **「保存视图（Save View）」**立刻保存。
- **从没保存过的视图**默认：**底部演奏 Pad 区隐藏**；在 4 轨布局下，默认 4 碟机 + 4 条波形。
- 碟机重启后**自动恢复上次选中的视图**（原厂会忘）。视图存放在 `/data/enginex/` 下，由后台服务保管。
- 用途举例：View 1 做练歌（Pad 显示 + 2 轨）；View 2 做俱乐部演出（Pad 隐藏 + 4 轨大波形）。

### 3.4 屏幕上的 8 个 Pad 方框

屏幕底部的 Pad 区是原厂的**状态指示**（显示当前 Pad 模式和各 Pad 的状态）。**用机身上的橡胶 Pad 操作**，在屏幕上点方框不是原厂设计的演奏方式。新建的视图默认隐藏这块区域，把屏幕空间留给波形。

## 4. Stems、DSP 与限幅

### 4.1 Stems 四轨分离

- 全机型解锁：在 **SC5000 / SC6000 / PRIME 全系**的曲库侧边栏出现 `Stems` 歌单，Pad 区有四轨独立静音。
- 四轨：**Vocal（人声）、Melody（旋律）、Bass（贝斯）、Drums（鼓组）**。
- 用法：在曲库里选歌时**向左滑动**，即可拆出四轨；加载后在 Pad 区切到 STEMS 模式，按 Pad 静音某一轨（比如抽掉人声做 Acapella，或只留鼓）。加载 Stems 曲目时 Pad 保持在 HOT CUE 模式（`#71`）。
- **流媒体歌也能拆**：把流媒体歌曲拖到 Stems 列表即可，EngineX 会用下载好的文件让 Engine 自己导入分轨。
- 分轨在哪里算：
  - **碟机本机**：不连电脑也能分，约为播放速度的 1.4 倍。
  - **电脑 / 云端**：同一局域网里的电脑运行 `tools/stems/run-home-worker.sh`（Windows 用 `run-home-worker.ps1`），碟机会自动发现并调用电脑显卡，一首 4 分钟的歌约 35 秒，不需要输入 IP 或密码。
- 分轨结果由 Engine 自己编码保存为原生 `.stems`；EngineX 不会伪造别的格式。

### 4.2 波形缩放（`#77`）

- 一体机（PRIME 4 / PRIME 2 / PRIME GO / Mixstream Pro / SC LIVE）的波形最远缩到 **30 秒**，和 SC5000 / SC6000 一致（原厂只有 10 秒）。
- 打开：`设置 → 设备 → 旋钮行为（Encoder Behavior）` 选 **波形缩放（Waveform Zoom）**，打碟界面转 Browse 旋钮即可。

### 4.3 DSP：防爆音、软限幅、自动增益

- 主要选项在 `配置 → 播放`（`Profile → Playback`；原厂主输出限幅在 `设置 → 混音台`）：

| 选项 | 默认 | 作用 |
| --- | --- | --- |
| `0dB 防破音软限幅`（Master Soft Clipper，`#58`） | 关 | 用平滑曲线把主输出压在 **-0.1 dBFS 以下**；-1.5 dBFS 以下的信号原样不动。零延迟 |
| `自动增益（0 dB 归一化）`（Auto-Gain，`#64`） | 关 | 把音量偏小的歌平滑提到接近 0 dBFS，最多 +9 dB，-42 dBFS 以下的静音不提升；开了之后一定会经过软限幅，不会爆音 |
| `回声淡出`（Echo Out；混音台页为 `推子回音 / Fader Echo`，控制中心另有快捷磁贴） | 关 | 开启后，一体机（PRIME GO / PRIME 4 等带通道推子机型）快速拉下通道推子，或单机播放器（SC5000 / SC6000）暂停切歌时，自动放出 2.2 秒平滑衰减的回声尾音（原理见下） |
| `原厂主输出限幅 (dB)`（`设置 → 混音台`） | 关 | PRIME GO / Mixstream Pro 放开了原厂的限幅，关 / 0–18 dB，可与软限幅并存 |

- 切换效果器时的「咔嗒」爆音已消除，两轨同时开效果器也有淡入过渡。Flanger 不再让音量下沉（自动补偿，最多 +6 dB）。
- 这些 DSP 都挂在音频链上，不增加延迟。
- **关于 Smart Loop**：仓库里没有 EngineX 自己的「智能循环」实现。Loop 用 Engine 原厂的 Loop / Auto Loop 功能；rekordbox 导入的 Loop 点会被保留。

**Echo Out 的原理：** 由底层 C 语言音频 DSP Hook 直接接管，在 44.1 kHz 主输出上挂一段环形延迟缓冲。开启后，无论是在一体机（PRIME GO / PRIME 4）上快速拉下通道推子，还是在单机播放器（SC5000 / SC6000）上暂停切歌，都会自动释放 **2.2 秒**丝滑衰减的回声尾音。尾音不会因为推子归零而被切断，也不会误开左上角的原厂 FX 灯。

### 4.4 智能同步（Smart Sync）

- **快速切换同步方式**：下拉控制中心，一键在 `BAR`（按小节）、`BEAT`（按拍子）、`TEMPO`（仅速度）之间切换。
- **自动扩程**：两首曲目 BPM 跨度超过当前变速范围（Pitch Range，如默认 `±8%`）时，按下机身 `SYNC` 键会自动把变速范围拓宽到 `±16%` 或 `±50%`，彻底解决大跨度 BPM 无法同步的问题。

### 4.5 转盘灯效

- `设置 → 设备 → 转盘灯效（Jog Light Mode）`：固定颜色 / 迷幻流光 / 迷幻频闪 / **迷幻 BPM 同步**（跟随当前曲目的拍点变色）。

## 5. 网页控制台、无线传歌与曲库修复

### 5.1 打开网页控制台

1. 手机或电脑和碟机连**同一个 Wi-Fi / 局域网**。
2. 在碟机上打开 `设置 → 关于`（About），屏幕会显示两行：**网页控制台地址**（形如 `http://<碟机 IP>:8080`）和**访问码**（`#79`）。
3. 浏览器打开该地址，输入访问码。登录后浏览器会记住，重启碟机也不会被踢掉。

关于访问码：

- **它不是 6 位数字**，而是碟机首次启动时随机生成的一长串字符（43 位），请直接对照屏幕输入或在手机上拍照。
- 保存在 `/data/enginex/state/access-token`；想换新码，删掉这个文件再重启碟机。
- 局域网内的人没有访问码就控制不了碟机；流媒体二维码链接**不会**打开控制台。
- 控制台是普通 HTTP，没有加密，只在信任的网络里使用；在不信任的场地可以干脆不连 Wi-Fi，U 盘、SD 卡和蓝牙播放都不需要联网。

### 5.1a 没有域名：免域名一键公网连接（Cloudflare Quick Tunnel）

没有域名的普通用户**不需要买域名，也不用配置反向代理**：

1. **碟机端一键开启**：在碟机 `:8080` 控制台直接点「开启免域名公网隧道 (Cloudflare Quick Tunnel)」，系统会按架构自动安装并启动 `cloudflared`，秒级生成 `https://*.trycloudflare.com` 公网 HTTPS 地址。手机用 4G/5G 流量即可远程打开控制台，碟机屏幕上的流媒体登录二维码也会自动使用该公网地址回调。
2. **自建 `enginex-relay`（兼容旧名 `sc5000-relay`）免域名启动**：运行 `enginex-relay -public auto`（或 `run-home-worker.sh --with-tunnel`），自动通过 Cloudflare Quick Tunnel 生成免域名公网 HTTPS 中继地址，并汇总管理多台碟机。

注意：`trycloudflare.com` 地址在隧道重启后会变化；公网访问仍需要控制台访问码，需要固定地址请改用自己的域名。

### 5.2 无线传歌（Wi-Fi Drop，`#66`）

1. 打开控制台，找到 Wi-Fi Drop。
2. 选目标盘：内置盘（eMMC，显示为内部存储）、SD 卡、U 盘；会显示剩余空间。
3. 在「歌单」栏填一个名字（默认 `Wi-Fi Drop`）。
4. 把 MP3 / FLAC / WAV / AIFF / M4A / AAC / OGG / OPUS 文件拖进页面。
5. 文件存到 `<盘>/Wi-Fi Drop/<歌单>/`。曲库所在盘上的 FLAC / MP3 会自动分析并加入同名歌单；其他文件会出现在 Engine 的文件浏览里，加载时再分析。

安全限制：不会覆盖已有同名文件；始终给盘保留 **256 MiB** 空间；单个文件不超过 FAT32 的 4 GiB 限制；Wi-Fi 实测速度约 9~10 MB/s，大批量传歌请接**千兆有线网口**（解锁到 1 Gbps）。

### 5.3 丢歌红字：一键重定位修复（`#74`）

场景：U 盘上的文件被你移动或改名后，碟机里该曲目显示红字（找不到文件）。

1. 控制台里找到曲目重定位（丢失曲目），选对应的盘，点 **「扫描」**。扫描只预览，不改任何东西。
2. 它会为每首丢失的曲目找新位置：先按**文件名 + 大小**，再按**忽略大小写的文件名**，最后按**清理后的文件名**。
3. 确认没问题再点 **「一键修复路径」**。修复前会先**备份 `m.db`**，再改写路径。
4. 完成后，在碟机上**重新加载那张盘**（拔插一次或重新选择）。

这个功能只有网页入口，碟机屏幕上没有。

## 6. FAQ

### 流媒体

**1. 支持哪些流媒体？有 QQ 音乐吗？**
网易云、Spotify、Deezer、SoundCloud、TIDAL、Beatport、Apple Music，共 7 个。QQ 音乐目前不支持。

**2. 二维码扫了没反应？**
先确认手机和碟机在**同一个 Wi-Fi**；手机用移动数据是打不开的。网易云必须用网易云 App 里的「扫一扫」，不能用相机或微信。二维码过期了就点屏幕上的「换一个新二维码」。

**3. Apple Music 有 Face ID 扫码吗？**
没有。用手机页的 Apple Music 登录，或粘贴歌单链接，见 1.3。

**4. Apple Music 能直接播吗？**
能。EngineX 解锁了 Engine 5.3.0 自带的 Apple Music 音源，由它直接播放，不再借 Deezer 或网易云。

**5. 登录后过几天又要重新扫码？**
令牌有自动续期，一般不用。但如果你改了密码、对方平台撤销了授权，或网易云 / Deezer 登录本身过期，就要重新扫一次。

**6. 俱乐部里别人扫我屏幕上的二维码会怎样？**
二维码只登录对应的流媒体服务，打不开控制台，拿不到碟机控制权。访客登录的会话 8 小时后自动到期，也可以点「结束账号会话」。

**7. 提示 Track not found？**
这个问题在 5.3.0.2 修了（`#73`）：后台服务重启后，流媒体歌单仍然能加载。如果还出现，重新进入一次歌单。

**8. 流媒体歌为什么每次不用重新下载？**
下载后缓存在碟机内部存储，再次加载直接秒开。各平台缓存相互独立（Spotify、Beatport、SoundCloud、官方直连模式的网易云各用自己的缓存）；网易云开了「Deemix 优先」时与 Deezer 共享无损缓存，换着点同一首不会重复下载。详见 1.4。

**9. Spotify 还需要自己建应用、申请 Client ID 吗？**
不需要。用 Spotify Connect 在设备列表里点 `EngineX OS` 即可一键绑定，或在碟机上点 Spotify 右侧的「扫码登录」，见 1.2a。Spotify 曲目直接拉取 320kbps Ogg Vorbis 原生音频，不走 Deemix 或网易云。

**10. OmniSource 搜不到 U 盘里的歌？**
先确认已开启；U 盘里要有 Engine 曲库（`Engine Library/Database2/m.db`）。WAV / AIFF 不在列表里。

### Rekordbox 与 CDJ

**11. 插上 Rekordbox U 盘需要先转换吗？**
不需要。插上就读，通常 2 秒内完成。

**12. Hot Cue 颜色会保留吗？**
会。Rekordbox 的 Hot Cue 颜色导入到 Engine 的 A–H 八个槽。没有 RGB 颜色的老 Cue 用先锋默认色。

**13. Memory Cue 去哪了？**
第一个 Memory Cue 对应主 Cue 点。全部 Memory Cue 保存在扩展表里，但原厂界面不能全部显示，也不会拿来填 Hot Cue 槽。

**14. 天龙连不上先锋 CDJ？**
检查是否在同一子网、是否打开了 `Pro DJ Link 曲库`。这是测试版功能，开发者没有先锋实体机，遇到问题请到 [OpenProLink](https://github.com/Cd1s/OpenProLink) 或本仓库反馈。

**15. 先锋 CDJ 看不到天龙的 U 盘？**
确认已打开 `Pro DJ Link Export to CDJ (Beta)`；U 盘里要有 `PIONEER/rekordbox/export.pdb`；换盘后要关再开一次。

**16. CDJ 能播放天龙下载的流媒体歌吗？**
可以（`#100`）：CDJ 上会有 `EngineX Streaming` 文件夹。该功能在工作区开发中，以发布说明为准。

**17. 天龙和 CDJ 谁当 Master？**
同一时间只有一个，可双向交接。

**18. U 盘异常拔出后数据库损坏怎么办？**
碟机会自动修复，不需要手动处理，也不会再弹「未安全弹出」报错。

### 4 轨与视图

**19. 4 轨一定要两台碟机吗？**
一台也可以开 4 轨布局，但另外两轨没人驱动；通常是两台 SC5000 / SC6000，或一台加一台 CDJ-3000。

**20. 影子轨道为什么没有声音？**
影子轨道只负责显示和跟随，不出声。声音只来自你负责的那两轨。

**21. 跟 CDJ 时为什么没有对端的 Hot Cue 标线？**
CDJ 不通过 Pro DJ Link 报告 Hot Cue。跟另一台 EngineX 碟机时有。

**22. 为什么屏幕上的 8 个 Pad 方框默认不能手点？**
那是 Engine 原厂设计的状态指示，实际演奏用机身橡胶 Pad。新视图默认隐藏这块区域，把空间让给波形（`#99`）。

**23. 重启后视图/布局又变回去了？**
5.3.0.2 及以前的 Engine 每次重启都会忘记选中的视图；`#99` 之后会恢复上次选中的 View。

**24. 开 4 轨布局后碟机重启了一下？**
正常，Engine 要重启才会应用这个开关。

### Stems 与声音

**25. 本机分轨要多久？**
约为播放速度的 1.4 倍；连同网电脑或云端，4 分钟的歌约 35 秒。

**26. 分好的 Stems 在哪里？**
曲库侧边栏的 `Stems` 歌单里自动归类。

**27. 开了「0dB 防破音软限幅」会让声音变小吗？**
-1.5 dBFS 以下的信号原样不动，只在接近满幅时才压。不会整体变小。

**28. 自动增益会爆音吗？**
最多提 9 dB，且之后一定经过软限幅，不会爆。它默认关闭。

**29. 开了 3-Band 波形，原厂波形没了？**
可以随时在 `波形样式` 或控制中心波形磁贴切回 Denon。

### 封面、网络与其他

**30. 转盘中心圆屏现在显示封面吗？**
4 轨布局下，转盘屏之前跟着一个空的第 1 轨，显示的是 Logo。现在改为跟随你负责的两轨，所以显示的是正在播放那首歌的封面（工作区修复，随下一版发布）。

**31. 另一台碟机上看不到我这首歌的封面？**
5.3.0 通过 Engine Link 给其他碟机发送封面时，只认 20 字节的二进制哈希加 `Artwork/<哈希>.jpg` 文件。旧版本写的是 40 位文本哈希，所以其他碟机没封面。新版本导入时会自动转换，转换完成后再让对方重新加载。

**32. 控制台打不开？**
地址和访问码在 `设置 → 关于`。碟机和浏览器要在同一网络，端口是 8080。

**33. 怎么用 SSH？**
默认没有 SSH 密码，公开固件也不内置任何公钥。把你自己的公钥放进 `/data/enginex/authorized_keys`（旧路径 `/data/sc5000-custom/authorized_keys` 因软链接同样有效），重启后生效，只能用密钥登录。

**34. 怎么在屏幕上关机？**
`设置 → 设备 → 电源 → 关机`（`#78`），会弹出原厂的「关机」确认框。

**35. 在线升级怎么用？**
连上 Wi-Fi 或网线后，`设置 → 关于 / 更新` 里点「更新」。二代机首次装好 `/data` 数据包之后，同样在这里一键升级（`#86`）。

**36. 想让新插的 U 盘自动分析？**
`设置 → 曲库 → 自动分析插入的设备（暂不可用）` 目前只保留偏好，不会自动提交分析任务；未分析曲目仍可由 Engine 在加载时分析。

**37. 开了 Live Stream: ON，电脑上怎么收听 / 直播？**
先在碟机下拉控制中心把 `Live Stream` 点为 **ON**，再选一种用法（地址里的 `<碟机IP>` 换成碟机的局域网 IP，写作时这两个地址尚未随当前 Release 发布）：

- **用法一：电脑免配置直连（最简单）。** 电脑不用装任何服务端软件，在 **OBS**（添加「媒体源」→ 取消勾选「本地文件」→ 填地址）、**VLC** 或**浏览器**里打开：
  - MP3 直播流：`http://<碟机IP>:8080/live.mp3`
  - WAV 无损流：`http://<碟机IP>:8080/live.wav`

  直接收到碟机数字内录的主输出声音，外置声卡和录音线都省了。
- **用法二：推送到外部 Icecast / Shoutcast 服务器。** 在电脑浏览器打开 `http://<碟机IP>:8080` 的 Web 控制台，在 Live Stream 卡片填入外部 Icecast 服务器地址、挂载点和密码。碟机在空闲的 CPU3 核上后台自动推流，并实时同步当前播放的歌名。

**37a. 电脑刷机工具看不到 PRIME GO / SC5000 / 其他一代机？（`#104`）**

> **推荐：免电脑 U 盘直接刷。** 一代机（SC5000 / SC6000 / PRIME GO / PRIME 4 / PRIME 2）不用连电脑：把 `*-Update.img` 放进 FAT32 / exFAT U 盘**根目录**，插到碟机上，进入 `Settings → Update → Reboot` 即可更新或恢复固件。
>
> **电脑 USB 线刷模式：** 正常开机打碟时，电脑**绝对看不到**刷机设备！必须先在碟机屏幕点 **`Settings → Update → Reboot to Computer Update Mode`**（重启进入蓝屏电脑图标的 Fastboot 模式），再用 USB-B 线连电脑运行刷机工具。

**38. 万一出问题，怎么恢复？**
卸载二代机数据包：`sh /data/enginex/bundle/uninstall.sh && reboot`（旧路径同样可用）。一代机用官方固件重新刷即可。**不要在实机上执行 Factory Reset 来测试功能**，它会清空设置。
