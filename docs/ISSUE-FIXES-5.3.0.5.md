## 1B. 仍在进行、没有合入 5.3.0.5 候选的工作

以下都**不是本版本已完成的内容**，用户文档里不得写成已有功能。

- **二代 32 位机 HFS+ 读写（`lklfuse`，进行中）**：二代 32 位机的内核强制模块签名（`MODULE_SIG_FORCE`）且被 LoadPin 锁定，没法加载自己的模块，也没法换内核（维护者：不换内核）。方案是用 LKL（把 Linux 6.12 内核当库用）加 FUSE 做用户态挂载：`lklfuse`（armhf 4.4 MB，LKL 6.12 加 fuse 3.17.2，已移植 HFS+ 的 bug 修复）；QEMU armv7 HIGHMEM 里 4338 次操作的压力测试、预填充、脏弹出和重新插入都 `fsck` 干净，RSS 6–17 MiB，卸载比 `lklfuse` 退出早返回 74–1886 ms。Engine 与 `edisksd` 不拒绝 FUSE 类型（要用 `-o fsname=<块设备>`，钩子把 `/dev` 设备名规整好）。分支 `agent/5305-hfs-lkl-int` @ `f1728327`（原型 `agent/5305-hfs-lkl` @ `21fa1007`）：钩子里的二代 32 位集成、`fsck -y`、弹出与拔出处理、随二代数据包带 `lklfuse` 和 `fsck.hfsplus`。**没有在真机上跑过**；风险：`lklfuse` 以 `O_RDWR` 打开块设备且没用 `-o sync`（RK3288 上性能没测），写入时突然拔出仍可能丢脏缓存，干净弹出最多等 15 秒。**在此之前，二代 32 位机上的 HFS+ 盘保持只读。**

## SMB without kernel CIFS — proposed, not merged (#300)

Root cause: first-generation decks have no CIFS filesystem and lack sshfs / mount.davfs. The old mount API executed unavailable mounts, so the rekordbox computer source could not use a configured SMB share.

A pure-Go SMB2/3 client (github.com/hirochachacha/go-smb2, BSD-2, no cgo) now reads NAS folders as playlists (including a folder literally named root), searches filenames and downloads to the existing cache. The console adds/removes the existing single NAS configuration and never returns passwords or tokens. Legacy WebDAV URL credentials remain usable through the existing auth fields and are removed from response URLs. Saved NAS settings reload after reboot; connections open on demand. Filesystem mounts are not automatically restored after reboot. On no-CIFS decks the mount API keeps the SMB entry, verifies login and share listing, and reports mounted:false with a userspace status; errors and missing SFTP/WebDAV helpers are explicit. BH-GC2-14 mount truth remains covered.

rekordbox audio resolution is kernel-mounted share, then Go SMB using /api/mounts and rekordbox_share, then NFS, then the existing notice. SMB uses the same .rekordbox-cache budget, rbxCopy sharing and Range reader as NFS. TCP connection/login deadlines (3 s), read/write inactivity deadlines (30 s), and cancellation bound stalled servers without treating a short local cache-write pause as a dead connection. NAS cache keys include the share/base folder; mount status identifies verification as a saved snapshot. Configured filesystem shares accept direct-cable link-local addresses; NAS keeps the existing HTTP resolver/address policy for SMB dials too. Player announcements and NFS discovery are unchanged.

Regression tests: TestSMBNASBrowseSearchAndDownload, TestSMBNASAPIAndRebootReload, TestSMBRekordboxRangeAndSharedCache, TestSMBRekordboxWrongPasswordNotice, TestSMBRekordboxServerStopsMidCopy, TestSMBMountWithoutCIFSNeverExecutesMount, TestSMBDialStalledServerHasDeadline. Authenticated Samba fixtures require SMB3 and include accented filenames. Real macOS File Sharing and stock Engine playback remain hardware acceptance checks.
