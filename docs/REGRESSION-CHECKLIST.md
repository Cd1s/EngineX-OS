# EngineX OS Regression Checklist

Fixing a new issue or PR must never bring back an old bug or introduce a new one. Before changing a shared mechanism (`MASTER` / `Sync` election, `engine_ui_hook.c` patch sites, deck header layout, QML patch dicts, `stream-sync` shadow state, or installer/packer scripts), check its history (`git log -S`, issue numbers in tests, and `docs/ISSUE-FIXES-*.md`) and run this checklist before every release. Every new real-deck bug adds a row here.

Rows marked **`[NO AUTOMATED TEST]`** in the verification column do not yet have an automated unit or sandbox regression test and must be verified explicitly on the dual-deck / hardware setup until an automated test is added.
